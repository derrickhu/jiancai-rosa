# 集市卡片路线

> 外层是卡片路线，内层是摊面翻堆。山坞这一轮把「名叫岔路的卡」拿掉，改成可扩展的遭遇插件和场景图。

参考如鸢（代号鸢）的据点探索：进入一个区域后是若干张卡，点一张走一步，走过的路变明牌，选了这条另一条就断。本文把那套结构接到收摊集市上。

**只改外层，不动内层。** 摊位卡点进去照旧是 `docs/场景交互设计.md` 里定案的摊面翻堆。

## 和如鸢的关键差异

如鸢据点探索**没有倒计时**：压力来自体力、路线规划、走过变明牌。我们照抄这一点。

所以 150 秒全局倒计时**取消**。改成：

- **全局：天色（步数）。** 走一张卡耗 1 步，步数走完天黑收摊。
- **摊内：不再倒计时装箱。** 紧张感只来自天色。

## 一局结构

| 菜场 | 天色 | 层数 | 保底摊位层 | 独特内容 |
|---|---:|---:|---:|---|
| 巷口收摊 | 10 步 | 13 | 3 | 教学场。车道 + 旧事件。每局从「收摊老板 / 楼道口一把」抽 1 张 |
| 河沿早市 | 12 步 | 15 | 4 | 船坞支线、藕摊、刘伯、河滩采集。每局抽 2～3 |
| 山坞早集 | 12 步 | 15 | 4 | 小路 → 山洞采菌；菌摊；樵夫。每局都在 |
| 江边渔市 | 14 步 | 17 | 4 | 夜栈、鲜货筐、阿珠、船舱。每局抽 2～3 |
| 老城菜行 | 15 步 | 18 | 5 | 账房钥匙、后厨门、梁上咸货、青石巷。每局抽 2～3 |

生成顺序：公共权重池填非保底层 + **每场节拍池抽样**。不要五个场共用同一张 `CARD_WEIGHTS` 当全部内容。河沿 / 江边 / 老城每局抽 2～3 个独特模块，巷口抽 1 个。山坞小路和菌摊仍每局都放。

一局流程：选点页扣体力 → 卡片路线 → 摊位卡进去翻堆装篮 / 走进支线换场景 → 退回路线 → 天色走完或主动收工 → `ResultPanel`。

## 分支规则

- 竖向列推进，一屏 2～3 张可选卡，选了就往前，**同层其他卡作废**。
- 卡按**左中右三条道**摆，跨层对齐。走一张卡只能到**相邻车道**，最多两张：选了左边，最右边那张就够不着。这就是「岔路」——**走哪边**，不是当前这张牌印着「岔路」。
- 前方**两排卡同屏可见**（越远越小、越省字）。
- 当前那排落在**屏幕居中稍靠下**，下方留出的路面是走路过渡的去处。
- **不再生成名叫「岔路」的卡。** 走进 `branch` 遭遇才换底图、换后续层。
- **死胡同**耗 1 步且什么都没有，是选错的代价。
- 分支允许**汇合**，不要做成纯二叉树。
- 支线走完靠 `returnStack` 回到主路当前层之后。

|---|---|---|

| **河沿** | 船坞口 `branch`（刘伯、水边采集、潮退死胡同）；藕摊 `specialty: lotus`；主路刘伯；河滩 `gather`。每局抽 2～3。 | 翻牌记忆等小游戏仍不接。 |

| **江边** | 夜栈 `branch`（阿珠、网里漏鱼、潮漫死胡同）；鲜货筐 `specialty: nightcatch`；主路阿珠；船舱短支线。每局抽 2～3。不接补网小游戏。 | 小游戏契约可留，不挂卡。 |

## 遭遇插件

「这张卡长什么样」和「踩上去发生什么」拆开。`MapNode.encounter` 指向独立 handler：

| type | 干什么 |
|---|---|
| `rummage` | 进翻堆。可带 `stall` 或 `specialty`（菌 / 藕 / 鲜货 / 咸货） |
| `talk` | 半身像 + 选项。给菜可从池里掷；可给本局 `bag` 信物 |
| `gather` | 看得见的采集点，限次数。`bg` 换底，不写死山洞 |
| `branch` | 切 `sceneId`，换底图和该场景后续层 |
| `gate` | `{ need, pass }`。没信物走 `cardBlock` 发灰；有则执行 `pass` |
| `minigame` | 只认契约，不接 UI、不挂卡 |
| `peek` / `favor` / `deadend` / `recipe` / `freebie` | 旧事件卡迁过来的 handler |

`RunMode`：`'map' | 'rummage' | 'play'`。`play` 覆盖采集、对话等待、以后的小游戏。

本局口袋：`bag`（钥匙、信物，先不进冰箱）、`flags`（对话选过什么、进过哪个洞）。

## 小游戏契约

`src/sim/minigames.ts` 只定接口：`memory` | `match` | `merge`。`start` / `act` / `settle`。这轮**不挂任何小游戏卡**。漏网、河滩改成看得见的 `gather`。

## 走一步的手感

点卡不立刻结算，先演 0.34 秒：脚下这排迎面放大掠过并淡出，前方那两排顺着自己那条车道下移放大接位。够不着的卡原地淡出。

事件卡走完要**弹窗**，不能只发一条 toast：

| 卡 | 弹什么 |
|---|---|
| 地上一把 / 采集到的菌 | 不弹面板。菜从图中间冒出来，飞进顶栏篮子 |
| 街坊人情 / 空摊 | 半身像 + 一句台词 |
| 樵夫等 `talk` | 半身像 + 选项按钮，必须选一项 |
| 死胡同 | 没有半身像，一句旁白 |
| 走进小路 | 不弹。换底图本身就是反馈 |

## 卡池

公共权重仍是摊 / 白捡 / 空摊 / 人情 / 死胡同 / 收费摊 / 油纸。各场独特内容走 `marketBeats.ts` 节拍池，不靠把新卡型塞进 `CARD_WEIGHTS`。

摊位不必永远是五类大摊。`rummage.specialty` 指向专属货池。

## 门槛

卡片可以要求金币、厨艺、或身上有某件东西。不满足时卡片发灰并写清缺什么，**不要藏起来**。

## 明牌与熟客

走过的卡，下次进同一菜场直接显示名字。按菜场记卡型，不记节点 id。

## 不要做的

- 不要在卡片层加实时倒计时。
- 不要把「岔路」做成一张卡名。
- 不要五个场共用同一张权重表当全部内容。
- 翻牌记忆 / 连连看 / 合成的完整 UI 这轮不做。
- 钥匙不进跨局存档。
- 不改厨房或菜谱。

### 和上面策划的偏差，都是故意的

- **层数 = 天色 + 3**。层数等于步数的话天色永远刚好花完。
- **保底摊位是整层都摆摊**，同层不出重复摊型。
- **`piles` 按 nodeId 生成，不按摊型。**
- **明牌只管事件卡。** 摊位、小路、菌摊、樵夫永远写清楚。
- **加了「绕过去」兜底。**
- **车道只做三条。**
- **前方只画两排。**
- **走路过渡期间锁住 `_sync`。**
