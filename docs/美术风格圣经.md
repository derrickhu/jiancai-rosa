## 1. 视觉识别

**一句话：温暖、干净、可点的厨房与收摊市集。食材永远是完整的、刚从摊上捡来的，不是切好的料理素材。**

三条原则：

| 原则 | 判定 |
|---|---|
| **完整食材** | 茄子带蒂整根、蒜是整头、鱼是整条、蟹是整只。禁止横切面、薄片、去皮块、摆盘切片。熟菜才允许「做完」的状态。 |
| **剪影能读玩法** | 占格 `w×h` 必须从外形看出来：带鱼细长、冬瓜横块、香菜一小撮。缩小到 64px 仍能认出品类。 |
| **场景可点，不靠按钮墙** | 厨房/市集是空间。冰箱、菜板、锅、秤、菜篮是热区，不是底栏三个字。 |

参考：用户提供的休闲烹饪小游戏——干净描边、软着色、暖木色 UI。我们比它更「市集收摊」：灯偏黄、地面有水渍、食材带泥土/鳞光，但不脏乱、不猎奇。

## 2. 色板

| 角色 | 色 | 用途 |
|---|---|---|
| 木器 | `#8B5A2B` / `#C4A574` | 砧板、摊架、冰箱侧板 |
| 墙纸 | `#F3E2C6` | 厨房墙，暖纸色 |
| 地面 | `#D8C3A5` | 瓷砖/水泥，略旧 |
| 湿区青 | `#2A4A5A` | 水产、湿篮格 |
| 主 CTA | `#E07A3A` | 出门、出锅，橙色 |
| 钱 | `#E0A100` | 金币，不作大面积底 |
| 墨线 | `#2A2018` | 中等粗细描边，不是像素硬边 |
| 叶菜绿 | `#6BA368` | 叶菜摊记忆色 |
| 根茎土 | `#C4A574` | 根茎摊 |
| 蛋豆暖 | `#F4D58D` | 蛋豆摊 |
| 水产青灰 | `#6B8E9F` | 水产摊 |

禁止：高饱和霓虹、赛博、写实摄影、水墨、像素点阵。

后四个菜场（河沿 / 山坞 / 江边 / 老城）必须和巷口同一套卡通描边，不要越做越写实。摊位翻堆底和可点遮挡堆按「市场 × 摊位」各做一张，禁止五个场共用同一张桌子和同一团遮挡。

## 3. 镜头与密度

- 竖屏 **750×1334** 设计坐标，场景图 **9:16**。
- 厨房：略俯的 3/4 室内。空屋底图 + 独立设备图叠上去，升级只换设备图。
- 市集总览：同一透视的收摊小街，四个摊位左右错开，热区互不重叠。
- 翻堆：摊面特写，食材散落重叠，像浅筐/摊布，不是九宫格卡片。
- 图标：主体居中，透明底；占格按 `w:h` 外接矩形，不要强行正方形。
- 全图 **无文字、无数字、无水印、无 UI 框**（字由游戏叠）。

## 4. 落地管线（对齐 huahua / srpg-rosa）

1. Prompt 只进仓库 `docs/prompt/`。
2. 原图进仓库外 `game_assets/jiancai-rosa/assets/raw/`。
3. 切图 `split/` → rembg `nobg/` → `crop_trim` `final/`。
4. 确认后再拷进 `minigame/images/`。AI 母版不直接当运行时图。
5. 场景图可留白底/画满，不抠。食材/熟菜/小道具必须抠透明。
