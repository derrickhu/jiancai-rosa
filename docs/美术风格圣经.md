> 全项目视觉的唯一事实来源。生图 prompt 只许粘贴 [`docs/prompt/_style_block.txt`](./prompt/_style_block.txt)，不要在每个任务里另写一套风格。
> 玩法与热区见 [场景交互设计.md](./场景交互设计.md)。管线见下文「落地」。

## 1. 视觉识别

**一句话：明亮、可爱、可点的厨房与收摊市集。食材永远是完整的、刚从摊上捡来的，不是切好的料理素材。**

四条原则：

| 原则 | 判定 |
|---|---|
| **先明亮再谈氛围** | 场景图最暗块明度 ≥ 45%，主色块落在 75–92%。「旧」只许体现在款式和材质，不许靠压暗、脏渍、暗角。 |
| **完整食材** | 茄子带蒂整根、蒜是整头、鱼是整条、蟹是整只。禁止横切面、薄片、去皮块、摆盘切片。熟菜才允许「做完」的状态。 |
| **剪影能读玩法** | 占格 `w×h` 必须从外形看出来：带鱼细长、冬瓜横块、香菜一小撮。缩小到 64px 仍能认出品类。 |
| **场景可点，不靠按钮墙** | 厨房/市集是空间。冰箱、菜板、锅、秤、菜篮是热区，不是底栏三个字。 |

对标《动物夜市》这类微信休闲经营：奶油暖色、厚而柔的描边、Q 版角色常驻画面。我们的题材是收摊捡漏，可以更市井，但**不许更暗**。

### 夜场怎么画

市集是黄昏到入夜，但**不许整体压一层暗**。夜色只压天空和远景建筑（`#1E3A5F`），摊位、食材、主角保持 80%+ 明度并带暖黄打光。判定：把图缩到 64px，摊位和食材应该是画面里最亮的一块。

### 角色

厨房和摊位必须有人。主角 Q 版 2.5 头身，围裙长发（沿用 `hud_player` 人设，但 Q 化，不要写实动漫脸）。白菜吉祥物从教程角色升格为常驻小跟班。可爱感主要由角色承担，不靠场景堆装饰。

## 2. 色板

| 角色 | 色 | 用途 |
|---|---|---|
| 木器 | `#C98B54` / `#E4C39A` | 砧板、摊架、冰箱侧板 |
| 墙纸 | `#FFF1DC` | 厨房墙，奶油 |
| 地面 | `#F2E3C9` | 地砖，浅米 |
| 湿区青 | `#4E7E92` | 水产、湿篮格 |
| 主 CTA | `#FF8A3D` | 出门、出锅，橙色 |
| 钱 | `#E0A100` | 金币，不作大面积底 |
| 描边 | `#4A3427` | 深暖棕，中等粗细，不是近黑、不是像素硬边 |
| 夜空 | `#1E3A5F` | 只用于市集天空和远景，不铺满全图 |
| 叶菜绿 | `#7FB069` | 叶菜摊记忆色 |
| 根茎土 | `#E4C39A` | 根茎摊 |
| 蛋豆暖 | `#F7DFA0` | 蛋豆摊 |
| 水产青灰 | `#8FB4C4` | 水产摊 |

旧色板（`#2A2018` 描边、`#8B5A2B` 木、`#D8C3A5` 地）已作废，整体偏灰偏暗，是「画风阴暗」的直接来源。存量图按批次替换，不要新旧混用在同一屏。

禁止：高饱和霓虹、赛博、写实摄影、水墨、像素点阵、暗角压边。

后四个菜场（河沿 / 山坞 / 江边 / 老城）必须和巷口同一套卡通描边，不要越做越写实。摊位翻堆底和可点遮挡堆按「市场 × 摊位」各做一张，禁止五个场共用同一张桌子和同一团遮挡。

## 3. 镜头与密度

- 竖屏 **750×1334** 设计坐标，场景图 **9:16**。
- 厨房：**2:1 等距**（isometric / dimetric），规格见 [等距场景规格.md](./等距场景规格.md)。地砖和墙用 tile 平铺，家具是独立等距 sprite，房屋升级换 tile、房间变大，不再重出整张底图。
- 旧的正面单点透视空屋（`kitchen_room_{0,1,2}.jpg`）在等距全量落地后作废。
- 市集总览：同一透视的收摊小街，四个摊位左右错开，热区互不重叠。
- 翻堆：摊面特写，食材散落重叠，像浅筐/摊布，不是九宫格卡片。
- 图标：主体居中，透明底；占格按 `w:h` 外接矩形，不要强行正方形。
- 全图 **无文字、无数字、无水印、无 UI 框**（字由游戏叠）。

## 4. 落地管线（对齐 huahua / srpg-rosa）

1. Prompt 只进仓库 `docs/prompt/`。
2. 原图进仓库外 `game_assets/jiancai-rosa/assets/raw/`。
3. 切图 `split/` → rembg `nobg/` → `crop_trim` `final/`。
4. 确认后再拷进 `minigame/images/`。AI 母版不直接当运行时图。
5. 场景图可留白底/画满，不抠。食材/熟菜/小道具必须抠透明。
