# 等距场景规格

厨房、门口摊位、远期街区共用这一套。风格看 [美术风格圣经](./美术风格圣经.md)，生图风格段用 [`_style_block.txt`](./prompt/_style_block.txt) + [`_iso_block.txt`](./prompt/_iso_block.txt)。

## 投影

2:1 dimetric。逻辑像素，竖屏 750 宽。

```
TILE_W = 120
TILE_H = 60

screenX = originX + (gx - gy) * 60
screenY = originY + (gx + gy) * 30
```

反投影（点击找格子）：

```
dx = (sx - originX) / 60
dy = (sy - originY) / 30
gx = (dx + dy) / 2
gy = (dy - dx) / 2
```

`(0,0)` 是菱形最上角，gx 往右下，gy 往左下。

## 房间档位

| 房屋 | 格子 | 菱形宽 | 菱形高 |
|---|---|---:|---:|
| 0 陋屋 | 4×4 | 480 | 240 |
| 1 精装屋 | 5×5 | 600 | 300 |
| 2 雅致屋 | 6×6 | 720 | 360 |

三档都在 750 逻辑宽内一屏放得下，不靠缩放。**房屋升级 = 房间真的变大**，这是升级最直接的正反馈。

墙高 `WALL_H = 240`，只画后两面（左后墙沿 `gx=0`，右后墙沿 `gy=0`），无前墙。240 是按冰箱这类
高家具试出来的：再矮冰箱会顶出墙头。

## 放置

两种模式：

```ts
type Placement =
  | { kind: 'floor'; gx: number; gy: number; w: number; h: number }
  | { kind: 'wall'; wall: 'left' | 'right'; t: number; z: number };
```

- `floor`：占地 `w×h` 格。冰箱、灶台、泡沫箱、摊位。
- `wall`：贴墙挂件，`t` 是沿墙第几格，`z` 是离地高度。菜篮走这个。

## 锚点

家具 sprite 锚点 `(0.5, 1)`，对齐**占地菱形的最下角**：

```
anchorScreen = isoToScreen(gx + w, gy + h)
```

出图时把物件画在占地菱形上，底边贴合菱形下半部，两侧不要超出菱形宽。

## 图层与深度

```
地砖 tile  →  墙 tile  →  地面装饰  →  家具与角色（同层，按深度排序）
```

家具和角色在同一个容器里 `sortableChildren = true`，`zIndex` 取占地菱形**最下角**的 `gx + gy`，
也就是 `(gx + w) + (gy + h)`。占多格的物件用左上角排序会被前面的小物件穿过去。`wall` 挂件固定
排在地面物件之前。

地板和墙是大片平涂加一条勾缝，出图反而更糊更重，代码里直接画（[IsoRoom.ts](../src/gameobjects/kitchen/IsoRoom.ts)），
不占包体。AI 只出家具和角色。

## 收益

家具是每件每级一张独立 sprite，与房间档完全解耦——**同一张冰箱图能摆进任何房间任何格子**。
旧的单点透视下每件家具都要对死那一个固定机位，换房子就得重画一整套，这是换视角最实际的收益。

房间本身零贴图，所以房间能任意变大、能画可放置高亮格、门口摆摊和远期街区复用同一套地面。

## 出图要求

- 严格 2:1 等距，**不要**真实透视，远处物体不缩小。风格段用 `_style_block.txt` + `_iso_block.txt`。
- 单件物件出图：纯色键底待抠，物件居中，不带地面阴影（阴影由程序画椭圆）。
- 键色写「pure magenta #FF00FF」，但模型实际会给 `#DC028C` 一带，所以
  [`cut-magenta-bg.py`](../scripts/cut-magenta-bg.py) 从四角采样取键色，不写死。
- 去键是全图的，不只挖和边缘连通的那片——摊位棚顶下、货架格里都是被物件围住的背景洞。
  代价：**物件本身不许用玫红/品红**，否则会被一起抠掉。
- 生图时说「只要这一个物件」还不够，附参考图会把模型带回去画整屋。加一句
  「no room, no walls, no floor, no people」，或者干脆不附参考图、把风格写进文字。
- 光从左上来，与场景一致。
- 其余同风格圣经：明度下限 45%，描边 `#4A3427`。
