# 捡菜市集 MVP

收摊捡漏：点摊位翻堆、检视品质、装进有限菜篮，赶在收摊前撤离。回家卖掉或做成 3 道菜，升级菜篮。

- 单局 150 秒：付钱买下收摊剩货，在老板装箱走之前挑拣。不是偷。
- 菜篮 6×5，左 2 列湿区
- 厨房：冰箱分食材/饭菜，炒锅选菜谱做菜进冰箱，再卖掉。做菜给厨艺经验，中后期升级家具还要厨艺等级。

微信开发者工具打开仓库根目录（`miniprogramRoot` 指向 `minigame/`）。改代码后执行 `npm run build`。

美术按菜篮格子比例出图：`src/sim/items.ts` 里的 `w×h` 即占格，例如带鱼 1×4、冬瓜 3×2。一张图对准一块占格外接矩形，不要做成统一方图标。
