# 厨房家具 · 10 级形象

等级 `0`–`9`。贴图 `subpkg_kitchen/kitchen_{id}_{level}.png`，没有则回落到更低级。GM 可预览每一级并单独摆坐标。

风格只许用 [`docs/prompt/_style_block.txt`](./prompt/_style_block.txt)。图内无文字。

## 房屋 3 档

屋子本身也升级。空屋底图 `subpkg_kitchen/kitchen_room_{0|1|2}.jpg`，只画墙、地、门、窗，门把手不挂袋、墙上不挂钩，避免和后来叠上去的菜篮搞混。三档**同一机位、同一房间大小**，固定视角，不能左右拖。升级只换墙纸、地板、门窗的材质和配色。

镜头锁死陋屋：左门、右窗、进深、地砖消失点都对齐 `kitchen_room_0.jpg`。中间不要隔墙或柱子。家具坐标默认跟陋屋同一套。

| 档 | 名字 | 底图 | 观感 | 家具上限（0–9） |
|---|---|---|---|---|
| 0 | 陋屋 | 竖版小单间 | 麦黄剥落壁纸、旧陶土地砖、薄木门；镜头基准 | 冰箱/菜篮 ≤3 级，其余 ≤2 级 |
| 1 | 精装屋 | 同机位竖版 | **晨光奶油**：浅奶油墙、浅石砖、白门、浅橡木踢脚，大白天光 | 冰箱/烹饪台/菜篮 ≤5，泡沫 ≤4（泡沫箱，未到保温箱） |
| 2 | 雅致屋 | 同机位竖版 | **暖白浅橡**：织纹白墙、浅色木地板、白门金把手，明亮高档 | 全部 ≤9 |

升级费用：陋屋→精装屋 200 金币，精装屋→雅致屋 520 金币。家具升到本档上限时提示先装修房屋。

旧存档若已有更高等级家具，会自动升到刚好装得下的房屋档。

## 冰箱 fridge

从小旧单门长到法式对开。3/4 侧视。0–5 级走奶油复古；**5 级奶油上下双门是好看基准**，6 级起必须明显更大、更好看，并换颜色（含银色对开）。卡通金属即可，不要霓虹不锈钢高光。

| 级 | 形象 |
|---|---|
| 0 | 迷你旧单门，发黄掉漆，又矮又窄 |
| 1 | 略高的旧单门，漆面斑驳 |
| 2 | 干净的小白/奶油单门 |
| 3 | 中等单门，圆把手，更稳 |
| 4 | 奶油单门微开，顶上罐子 |
| 5 | **基准**：奶油上下双门，圆角复古，已经很好看 |
| 6 | 明显更宽的奶油法式对开（双门+下层冷冻抽） |
| 7 | 再大一号，换浅天空蓝/湖水绿搪瓷，香槟金把手 |
| 8 | 大号拉丝银对开门，卡通金属，现代 |
| 9 | 最大不锈钢法式对开，带饮水凹槽暖光 |

回家后干湿饭菜都进冰箱，共用这些格，不分仓。塑料袋/菜篮和泡沫箱只决定**出门时**干区、湿区有多大。

## 炒菜区 cook / 墙上菜谱 recipe

**已下架。** 炉子和墙上菜谱不再单独出现。做饭点前景烹饪台。

## 烹饪台 table

桌子 + 灶是同一件家具。机位和冰箱一样：略俯 3/4，看见正面、右侧一点和浅台面，要能落在地砖上。用**台面材质**和**灶/锅**拉开等级。**岛台起改电磁炉**。锅必须能炒菜：高级不粘炒锅、陶瓷煎锅/炒锅，平底浅帮斜壁，不要黑铁锅，也不要只会炖煮的高帮奶锅。每级锅的颜色和款式要换。图内无文字，锅里不要食物。

| 级 | 阶段 | 桌子 | 灶 / 锅 |
|---|---|---|---|
| 0 | 简陋桌 | 歪斜小矮木桌，糙板、缺角 | 瘪旧黑铁锅，底下两块砖头支着 |
| 1 | 简陋桌 | 旧方桌，四条细腿还在晃 | 锈斑小炒锅 + 廉价卡式炉 |
| 2 | 木桌 | 较稳的厚板木桌 | 普通黑铁锅 + 单头煤气罐炉 |
| 3 | 蛋卷桌 | **质变**：露营蛋卷桌，浅桦木条+细铝框 | 干净卡式炉 + 空锅 |
| 4 | 蛋卷桌 | 更长的蛋卷桌，铝脚更利落 | 更好的单头炉 |
| 5 | 岛台 | 奶油短柜，浅木台面 | 电磁炉 + **奶油陶瓷炒锅**（灶上）+ 小珐琅锅 |
| 6 | 岛台 | 同体量奶油岛台 | 电磁炉 + **灰色不粘炒锅** + 绿色陶瓷煎锅 |
| 7 | 石台 | 同体量浅石英台 | 电磁炉 + **陶土红陶瓷炒锅** + 白不粘煎锅 |
| 8 | 大理石 | 同体量大理石 | 电磁炉 + **香槟金不粘炒锅** + 奶油陶瓷平底锅 |
| 9 | 大理石 | 同体量最高档 | 电磁炉 + **大号白陶瓷炒锅** + 木柄不粘煎锅 |

陋屋最高 3 级（还是带腿木桌）；精装屋到蛋卷桌/短岛台；大理石中岛要雅致屋。

## 菜篮 basket

出门装干货的容器，挂在墙上钩子上。每隔几级换形态，同形态内再变大变精致。

| 级 | 阶段 | 形象 |
|---|---|---|
| 0 | 塑料袋 | 挂在钩上的薄超市塑料袋，皱、半透明，开口朝上能装东西 |
| 1 | 塑料袋 | 更厚更大的塑料袋，袋口打结挂着 |
| 2 | 小菜篮 | **质变**：小小竹/藤菜篮，旧、浅 |
| 3 | 小菜篮 | 稍大，编织更整齐 |
| 4 | 菜篮 | **质变**：正常市集藤编挂篮 |
| 5 | 菜篮 | 更深更大的单层藤篮 |
| 6 | 菜筐 | **质变**：竹筐/木条筐，绳挂在钩上 |
| 7 | 菜筐 | 更大更结实的菜筐 |
| 8 | 双层 | **质变**：双层挂篮 |
| 9 | 双层 | 宽大精致双层菜篮 |

市集格子随等级变大。

## 泡沫箱 foam

装湿水产。1 级必须能看出「能装东西」。每隔几级换形态。

| 级 | 阶段 | 形象 |
|---|---|---|
| 0 | 水桶 | 小小旧塑料水桶，开口朝上，细提手，能装水/鱼 |
| 1 | 水桶 | 更大的旧水桶，铁丝提手，桶身更高 |
| 2 | 泡沫箱 | **质变**：小开口白泡沫箱，能看见内腔 |
| 3 | 泡沫箱 | 带盖的白泡沫箱 |
| 4 | 泡沫箱 | 更大更整齐的泡沫箱 |
| 5 | 保温箱 | **质变**：带提手的塑料保温箱 |
| 6 | 保温箱 | 更厚实、扣盖的保温箱 |
| 7 | 保温箱 | 专业冷链箱，卡扣 |
| 8 | 双层 | **质变**：上下双层保温箱 |
| 9 | 双层 | 更大的双层/叠放专业保温箱 |

额外容量：`+ foamLevel`。

## 玩家怎么升

厨房顶栏 **装修**：先装修房屋，再升级家具。花钱升级会换外形，隔几级换成新家伙。菜篮/泡沫热区仍可直接点升级（受房屋档限制）。GM 用 **屋+/屋-** 预览三档房子，**级+/级-** 预览家具外形并单独摆坐标，导出后固化。
