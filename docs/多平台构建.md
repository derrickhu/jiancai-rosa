# 多平台构建（微信 / 抖音）

游戏内容一份，平台差异只在壳和宿主 API。对齐消消、花花：`minigame/` 是真源，`build/<端>/` 是开发者工具打开的目录。

## 命令

| 命令 | 打开哪里 |
|---|---|
| `npm run build` | `build/wechat/` 和 `build/douyin/` |
| `npm run build:wechat` | 只出微信 |
| `npm run build:douyin` | 只出抖音，提审用这个 |

微信工具继续开仓库根目录。抖音工具开 `build/douyin/`。不要开 `minigame/`。

## 两端已经分开的东西

- 存档 key：微信 `jiancai_*`，抖音 `jiancai_tt_*`。经分 gameKey 仍是 `jiancai`，用 platform 字段区分。
- 云存档集合：`jiancai_playerData` / `jiancai_tt_playerData`。
- 登录：微信 `wx`，抖音 `dy`。抖音 `tt.login({ force: true })`。
- 游戏圈只在微信。抖音厨房左侧是「福利」：侧边栏每日 50 金币，添加到桌面一次 100 金币。
- 激励视频广告位按宿主拆开。抖音已接菜篮加行、体力、特殊菜场。插屏在从菜场回家进厨房时播。
- 抖音包的 CDN 忽略名单从微信 `platform/wechat/project.config.json` 抄过去，大图不进代码包。
