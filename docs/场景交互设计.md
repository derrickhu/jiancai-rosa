# 捡菜市集 · 场景交互设计

把 demo 底栏按钮收进两个空间：**自家厨房**、**收摊市集**。规则层不改，只换点击对象。

## 厨房（原首页）

竖屏一间小厨房。玩家站在灶台前看进去。

底图只画**空屋**（墙、地、门、窗），门把手不挂袋、墙上不挂钩；菜篮挂钩等一律是后来叠上去的独立图。房屋 3 档换图，**同一陋屋机位、同一大小、固定视角**：陋屋是麦黄旧砖；精装屋换晨光奶油浅石砖；雅致屋换暖白浅橡木地板。冰箱、烹饪台（桌子+锅）、墙上菜篮、泡沫箱是独立 PNG，按升级等级换 `subpkg_kitchen/kitchen_{设备}_{等级}.png`。墙上菜谱和独立炉子已去掉。大件家具升级和房屋档挂钩，没装修上去升不了。每件家具正上方有圆形上箭头：点开浮层看名称、等级和金币按钮，钱不够或要先装修时按钮发灰点不了。房屋升级也是同一套箭头，放在门框上方，和门上「出门」热区分开。厨房左下有 GM 摆放：拖家具、大小、导出布局，摆好后把剪贴板内容发回来即可固化。

| 场景物 | 大约位置 | 对应 demo | 点击 |
|---|---|---|---|
| 门上方箭头 | 门框顶上 | 装修房屋 | 打开房屋档浮层，花钱升到下一档 |
| 门 / 出门 | 左上门扇中下部 | 去市集收摊 | 先进入选点页，确认菜场后再扣体力 |
| 冰箱 | 正后方偏右 | 库存 | 打开冰箱页：食材 / 饭菜混放，回家后不分干湿 |
| 近景烹饪台（桌子+锅） | 前景 | 合成 | 打开烹饪页：选菜谱看材料，够了就做，熟菜进冰箱 |
| 墙上空菜篮 / 塑料袋 | 左墙挂钩 | 出门干区 | 升级出门篮右边干货格子 |
| 冰箱旁泡沫箱 | 冰箱脚边 | 出门湿区 | 升级出门篮左边湿货列 |

顶部只留 **钱、体力、厨艺**。做菜加经验，升厨艺；中后期家具和装修除了金币还要厨艺够。场景里不叠「出门 / 冰箱」等字，底部也不再有操作提示。蔬菜图鉴已下架。

后续可加：锅气、开门灯、秤指针，都挂在这些热区上，不另做按钮。

## 出门选点

点门后先到「今晚去哪收摊」。每张卡一个菜场缩略图。未达等级的显示锁定。

| 菜场 | 解锁 | 现在 |
|---|---|---|
| 巷口收摊 | 1 级 | 开放。四摊旧货，水产六种均分（含蟹、黄鱼） |
| 河沿早市 | 4 级 | 锁定。菜更多、开肉摊；水产只出小鱼/花蛤/海带。螃蟹不当常规，约 0.5% 漏网。虾、带鱼、黄鱼留江边 |
| 江边渔市 | 8 级 | 锁定。水产主场，蟹、黄鱼、虾常见 |

选中开放菜场才扣体力并进入该场卡片路线。冰箱满了不能出门，先卖掉或做菜腾位置。市集顶栏能看见冰箱还空几格。篮里装走的都带回家，坏的也进冰箱，不会在路上随机丢掉。带回来的比空位多，回家要自己勾选卖掉哪些（刚带回或冰箱里的），勾够才能进冰箱，不会替玩家乱卖。回家不扣体力。厨艺经验见 `docs/人物等级与经验.md`。

## 市集

### 卡片路线（外层）

四摊固定热区的总览已经下线，换成卡片路线，规则与卡池见 [docs/集市卡片路线.md](./集市卡片路线.md)。翻堆和菜篮两节不受影响。

一屏是收摊小街的纵深底图，卡片按**左中右三条道**摆，跨排对齐。最下面一排是脚下能点的 2～3 张，往上两排是前方的路，越远越小、也点不动，只给情报。排与排之间画连线：走哪张卡能到前面哪几张，点之前就看得见。

**方向是硬约束**：一张卡只通到相邻车道，最多两张。走左边那张，最右边那张就够不着了。岔路例外，它把下一排整排打开。

脚下那排卡落在屏幕居中稍靠下，下方有个橙点是你现在站的位置，连线从这里散出去。身后走过几段写在左上角标题里。

点一张卡先演一段往前走：脚下这排迎面放大掠过并淡出，前方那两排顺着自己那条车道下移放大接位，够不着的原地淡出。演完才扣天色、才结算。

事件卡走完：白捡不弹面板，菜从图中间冒出来再飞进顶栏篮子；街坊人情和空摊是半身像加一句台词；死胡同只有旁白没有人。岔路不弹，0 步的卡要跟手。

顶栏：**天色**（剩几步）、金币、冰箱空位、篮子干湿、回家。进摊之后中间那格换成**装箱**进度。

| 卡 | 步 | 玩家看到的 |
|---|---:|---|
| 叶菜 / 根茎 / 蛋豆 / 水产摊 | 1 | 摊型缩略图 + `免费 / N 金币 · 剩 N 件` |
| 摊·好货（收费摊） | 1 | 同摊型的图 + 金币角标，进场费是常规的三倍多 |
| 岔路 | 0 | 绿色 `0步` 角标，走它不耗天色，还把下一排三道全打开 |
| 地上一把 / 死胡同 / 空摊 / 街坊人情 | 1 | 没走过时只显示背面和「？」，走过一次这个菜场就永久明牌。明牌之后也只写卡名，具体给什么要走完才弹窗 |

前方那两排照同样规则明牌，但只判钱和厨艺门槛，不判天色——走到跟前剩几步早变了。

一层的卡全进不去（钱不够又碰上整层摊位）时，卡下面会出「绕过去（耗 1 步）」，不会把人卡在路上。

天色走完是天黑被赶出来，掉新鲜度；主动点回家是从容收工，不掉。

### 食材三态

| 状态 | 图 | 操作 |
|---|---|---|
| 还在堆里 | 各摊专用遮挡堆（菜叶/泡沫/绳子/塑料袋），看不出里面是什么 | 点遮挡堆，随机抽出一件 |
| 已抽到桌上·未检视 | 看见是什么菜（坏的外形已蔫） | 点一下入篮或丢掉；品质仍是 ？ |
| 已抽到桌上·已检视 | 普通 / 新鲜 / 精品 / 坏了 | 确认后入篮更值钱 |

桌上底图里画着的菜只是摊面装饰。可抽的是叠在冰台/桌面上的那一堆，抽中会先放大到面前再落到一边。

### 翻堆（定案：摊面排布，不卡片）

卡片好做但像菜单。正式交互：

- 进入后是该摊的桌面特写（浅筐 / 冰台 / 布）。
- 摊上是各摊专用的大遮挡堆：叶菜盖菜叶布，根茎盖泡沫麻绳，蛋豆盖塑料袋蛋托，水产盖蓝布泡沫。看不出里面有什么。
- 点遮挡堆随机抽出一件：在堆上弹出认菜，马上落到桌上（第一层惊喜：抽到什么）。不挡连点，上一个还在飞也能再抽。每抽出一次，遮挡堆缩小一点，抽完消失，不要用变透明表示空。
- 桌上的菜可入篮，或按住看普通/新鲜/精品（第二层惊喜）。
- 装箱满了，堆里没抽走的和桌上没入篮的一起装走。
- 点食材或拖进左下角菜篮热区。

逻辑仍是现在的 `PileItem` 列表，只是坐标改成摊面上的散点，图标按 `w×h` 缩放。
