# 菜谱 / 新食材出图规划

图已按表进包。稀有度改版又补了 10 种食材（干净+坏）和 15 道新菜，提示词在 `docs/prompt/items_rarity_batch*.txt`、`dish_rarity_batch_prompt.txt`。现行菜谱以 `src/sim/recipes.ts` 为准。

## 落盘

| 阶段 | 路径 |
|---|---|
| Prompt | `docs/prompt/dish_*_prompt.txt`、`docs/prompt/items_new_*_prompt.txt` |
| 母版原图 | 本机 `.tmp_qc_recipes/raw/`（仓库外 `game_assets` 这次写不进去，原图先留在这，不进 git） |
| 成品 | `minigame/subpkg_images/` |

熟菜：`dish_{id}.png`（与现 `dish_tomato_egg.png` 一样，约 512² 透明）。  
食材：`{id}.png` / `{id}_dirty.png` / `{id}_rotten.png`。

已有三道不重做：`dish_stirfry` `dish_tomato_egg` `dish_garlic_shrimp`。

## 画风

只许 `_style_block.txt`：暖卡通、中粗深褐描边、软赛璐璐。**不要写实、不要 3D、不要照片。**  
食材必须整货：不切片、不剖面。熟菜才是装盘完成态。  
形态：干净（刚捡、能认）/ 脏（灰土、蔫边、不亮）/ 烂（褐斑、发蔫，**不要五官、不要猎奇**）。水产/肉也出这三态：脏=不新鲜发乌，烂=不能吃。
